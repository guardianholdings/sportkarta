# Reports

Generated by `scripts/quarterly-report`:

```bash
pnpm report:quarterly              # the quarter that has just ended
pnpm report:quarterly -- 2026-Q2   # a named quarter
pnpm report:grant -- --from 2026-04-01 --to 2026-06-30 [--municipality 12]
```

Each run writes three files with the same stem: `.html` (print-ready A4),
`.pdf` (rendered through Playwright's Chromium) and `.csv` (annex form, one row
per figure, Bulgarian field names).

The figures themselves are declared in `lib/src/reports/` — a metric is a
Bulgarian label, a definition, a unit, an SQL query and an additivity flag, and
every rendered report prints the SQL beside the number in its Methodology
section. `db/src/reports/reconcile.test.ts` holds them to the same standard as
`/statistika`: fixture-exact values, additive figures that sum across
municipalities to the national one, and coverage figures that agree with
`mv_national_stats`.

Artifacts are gitignored by default because a report generated from a
development database contains partial figures. Published reports are committed
deliberately (`git add -f`), so a quoted figure stays findable.
