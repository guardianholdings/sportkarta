**Select** — native `<select>` styled to match Input. Native for accessibility and mobile pickers.

```jsx
<Select defaultValue="all">
  <option value="all">Всички дейности</option>
  <option value="hike">Hiking</option>
  <option value="mtb">MTB</option>
</Select>
```

`size` sm|md|lg, `invalid`. Custom chevron built in.
