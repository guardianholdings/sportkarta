**Badge** — small status/label pill, non-interactive.

```jsx
<Badge tone="success">Отворено</Badge>
<Badge tone="accent" variant="solid">Ново</Badge>
<Badge tone="warning" icon={<Snowflake size={13} />}>Затворено зимата</Badge>
<Badge tone="brand" variant="outline">Умерено</Badge>
```

`tone` neutral|brand|accent|success|warning|danger|info · `variant` soft|solid|outline. Use for difficulty, open/closed, "new", ranks.
