**Stat** — a labelled metric with the value in the mono/tabular face.

```jsx
<Stat value="12,4 км" label="Разстояние" />
<Stat value="640 m" label="Изкачване" tone="brand" icon={<TrendingUp size={18} />} />
<Stat value="3-ти" label="Този месец" tone="accent" align="center" />
```

Use on profile headers, leaderboards, spot detail, and challenge progress. Pre-format the value (units, decimal comma for BG).
