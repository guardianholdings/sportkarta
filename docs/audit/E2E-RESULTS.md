# E2E execution results — audit run 2026-07-24

**Nothing here passed by code inspection.** Every PASS was produced by driving the
running stack (web :3000 dev, Postgres+PostGIS :5433, the real pg-boss worker) and
inspecting the database, the job tables, and the file-transport mail outbox directly.
Evidence lives in `docs/audit/evidence/` (**101 artifacts: 41 screenshots + 60
DB/job/mail captures**) and is referenced per row. Driver specs:
`scratchpad/audit/*.spec.ts` (Playwright, serial, real sessions).

**Stack & fixture.** Worker run on the host with `MAIL_TRANSPORT=file`. Fixture:
3 municipalities — **rich** Столична(239), **thin** Невестино(169), **empty**
Гурково(100) — plus a 3×3 status×source matrix and access variants in Невестино
(`00-fixture-facilities.txt`); 6 role accounts incl. a minor and an ambassador
**scoped to Невестино only** (`p2-users.json`). The e2e suite's own leftover rows
were present in the dev DB (noted in AUDIT-F2).

**One clock caveat, honoured:** logical clocks only. Time-dependent hops were driven
by backdated fixtures + injecting `now` into the real materializer and dispatching the
real reminder/digest jobs. No hop was silently skipped.

Legend: **PASS** executed, asserted, evidenced · **PASS\*** passed with a finding
attached · **UNTESTED** with reason.

## UNTESTED (with reason)

- **SMTP-disabled-in-production "sends nothing"** — cannot be exercised on a dev
  stack without a prod build + unset SMTP; asserted by `lib/src/email` unit tests.
- **Server-side PDF absence / `report:quarterly` Chromium path** — CLI render not
  driven this pass (documented behaviour; HTML admin annex was reachable).
- **Real camera scan of the QR** — the physical pixel-read hop was substituted by
  minting the token with the same lib+secret the organizer page uses; everything
  downstream ran through the real UI + DB.
- **Concurrency last-RSVP-slot race** — the order-only RSVP design makes over-booking
  structurally impossible (no counter); asserted by `db/src/sessions-waitlist.test.ts`
  rather than a live two-client race this pass.
